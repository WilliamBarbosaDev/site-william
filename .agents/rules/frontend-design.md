# Frontend Design Rules

Always apply the guidelines from `.agents/skills/frontend-design/SKILL.md` when designing, building, refactoring, or modifying UI elements, components, layouts, or copy in this repository.

## Core Rules:
1. **Distinctive & Intentional Design**: Ground visual choices in the subject matter (William Barbosa — Estratégia, UX/UI, Web & IA). Avoid generic templates, cliché card layouts, or AI-generated defaults.
2. **Typography**: Use intentional typography scales, clear font weights, active headline treatments, and line lengths under 80 characters. Avoid single-word bold/italic highlights in headlines or unnecessary ALL-CAPS eyebrow labels above every heading.
3. **Visual Structure & Content**: Ensure structural devices (borders, labels, numbering) encode actual information. Use sequence numbers (01, 02...) only for real sequential processes.
4. **Restrained Motion**: Use animations deliberately to draw attention or respond to user interactions. Avoid redundant, scattered hover effects on every card.
5. **Clear Copywriting**: Use active voice, simple plain language, consistent terminology, and conversational tone matching the brand.
